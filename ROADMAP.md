# Roadmap

Build one step at a time. These milestones describe the direction; implementation
choices can change as the project develops.

1. HTTP event ingestion
2. Event model and validation
3. In-memory processing
4. Async processing with Tokio/channels
5. Persistent storage
6. Querying/filtering
7. Batching and backpressure
8. Observability of Aevum itself
